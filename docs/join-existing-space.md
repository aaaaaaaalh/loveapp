# 已有空间加入对方空间

## 行为

「我的」页面的单人自建空间新增「加入对方的空间」入口。输入昵称和有效邀请码后打开对方空间；原空间、照片、留言、愿望和礼物全部保留，不自动合并，也不自动分享给新空间的对方。在「我的」可切换回来，选择保存在数据库，刷新后保持。

已有双人空间的账号不再加入其他双人空间。无效、过期、自己的邀请码或已满空间不会改变当前归属。每个空间仍最多两名成员，原空间照片仍受原有成员权限保护。

## 实现与验证

- 新迁移 `202610120001_join_existing_space.sql`：将账号唯一成员约束改为每账号最多一个活跃空间；保留原成员行和所有业务记录，增加受权限校验的切换及空间列表 RPC。原 RLS 和私有 Storage 不变。
- CloudGate 只加载活跃成员关系；新弹窗加入成功后重新加载，避免显示旧空间缓存。
- 数据库测试 9 项通过，包含原数据保留、失败回滚、切换权限、原空间对新伴侣不可见。
- 浏览器回归 22 项通过，新增已建空间加入、错误邀请码、关闭弹窗、刷新、切回原记录及 375px 布局检查。
- lint/build 通过；包体积提示仍存在。
- 官方 `db push --dry-run --skip-vault` 已执行，但 PostgreSQL TCP 连接超时，不能标记成功。随后用官方 `db query --linked` 执行新迁移事务并 ROLLBACK，预演成功，六张业务表 RLS 与私有照片桶保持启用。
